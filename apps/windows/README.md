# Windows Client Placeholder

The future client will use Tauri + React and the generated TypeScript client from `/api/v1/openapi.json`.

Planned first release:

- device binding with the website password;
- device token stored in Windows Credential Manager;
- resource library, tasks, notes, attachment upload and AI conversations;
- online-only operation with no local business database.

No installer or Tauri runtime is included in the current migration.
